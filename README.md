# centre-horizon-carrousel

Application web de diaporama de photos sous forme de carrousel, réalisée en HTML, CSS et JavaScript (projet de groupe).

## Fonctionnalités

- Affichage des photos avec leur titre et un texte alternatif pertinent
- Barre d'outils masquée au départ, affichée/cachée avec le lien « Afficher/Cacher »
- Boutons précédent / suivant avec navigation en boucle
- Lecture automatique (toutes les 3 secondes) avec démarrage/arrêt, un seul minuteur actif à la fois
- Photo aléatoire, jamais deux fois la même de suite
- Navigation au clavier avec les flèches gauche et droite
- Interface responsive (utilisable sur mobile)

## Technologies

- HTML5, CSS3, JavaScript (vanilla)
- Font Awesome (icônes)
- Google Fonts : Open Sans
